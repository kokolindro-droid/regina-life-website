# Regina Life Clinic Website Plan

## Goal and Primary Conversion
- **Primary conversion**: Book a free longevity assessment / consultation
- **Secondary conversions**: Download Longevity Guide, Subscribe to newsletter, Contact for corporate programs

## Market and Language
- **Primary market**: Bulgaria (Sofia and nationwide)
- **Languages**: Bulgarian (primary), English (secondary toggle)
- **Register**: Formal (Вие) - medical clinic context requires professional tone

## Regulated Vertical
- **Medical**: Yes - loads references/regulated-verticals.md before writing copy
- **Claims requiring verification**: biomarker counts, treatment efficacy, doctor credentials, patient outcomes

## Page Inventory and Sitemap
1. Homepage (index.html) - Bulgarian default with English toggle
2. About / Нас (about.html)
3. Services / Услуги (services.html) 
4. Programs / Програми (programs.html)
5. Team / Екип (team.html)
6. Diagnostics / Диагностика (diagnostics.html)
7. Blog / Блог (blog.html)
8. Contact / Контакти (contact.html)
9. Privacy Policy / Политика за поверителност (privacy.html)
10. Language toggle functionality on all pages

## Stack and Hosting Constraints
- **Stack**: Static HTML/CSS/JS (no build step required for simplicity)
- **Hosting**: GitHub Pages or similar static host
- **CMS**: None - content edits require code changes (acceptable for clinic with infrequent updates)
- **Assets**: Existing doctor photos, clinic interior shots, biomarker charts

## Success Metrics
- **Primary**: Monthly consultation bookings (target: 15-20 qualified leads/month)
- **Secondary**: Newsletter signups (target: 50/month), Program inquiries (target: 5 B2B/month)

## Design Inspiration from Benchmark
Based on Balkans-Medical-Longevity-Sites-Report.md:
- **Structure**: Video hero → 3-5 step journey → Programs → Team → Diagnostics → Proof elements → CTA
- **Motion**: Hero video, letter-by-letter headline reveal, stat counters, progress bars, carousels
- **Trust elements**: Named doctors with credentials, biomarker counts, specific tests, accreditations
- **Color palette**: Medical blues/teals with longevity greens/golds (from Blue Longevity Clinic reference)
- **Typography**: Clean sans-serif with good Cyrillic support

## Content Notes
- Bulgarian copy written natively (not translated)
- English version available via toggle
- All medical claims attributed to clinic or verifiable sources
- Team section features actual doctors with photos and specialties
